# 💰 Expense Tracker

A full-stack Expense Tracker web application that helps users manage their income and expenses, track transactions, and view monthly financial summaries.

## 📌 Project Overview

Expense Tracker is a personal finance management application where users can securely register and log in, add income and expense transactions, edit or delete transactions, search and filter transaction records, and view monthly financial summaries.

The project uses JavaScript for the frontend, PHP for backend/server-side processing, and MySQL for database management.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## ✨ Main Features

### 🔐 User Authentication

#### Registration
- Name
- Email
- Password
- Confirm Password

#### Login
- Email
- Password

### 🏠 Dashboard

The dashboard provides an overview of the user's financial activities.

- Total Balance
- Total Income
- Total Expense
- Recent Transactions
- Expense Category Overview

### ➕ Add Transaction

Users can add new transactions with:

- Transaction Type
  - Income
  - Expense
- Title
- Amount
- Category
- Date
- Description

### 📋 Transaction History

Users can view all their transactions in a structured table.

Information includes:

- Date
- Title
- Category
- Type
- Amount

### ✏️ Edit Transaction

Users can update existing transaction information.

### 🗑️ Delete Transaction

Users can delete transactions that are no longer needed.

### 🔎 Search & Filter

Transactions can be searched and filtered by:

#### Type
- All
- Income
- Expense

#### Category
- Food
- Transport
- Shopping
- Bills
- Education
- Entertainment
- Other

#### Date
- Today
- This Week
- This Month
- Custom Date

#### Search
Users can search transactions using keywords such as:

`food`
